## What this adds over the original Combat Hitboxes

- **Shield color** — a blocking player keeps a fully visible light-orange hitbox, it never disappears
- **Hit colors** — red when you can hit, white when you can't
- **Projectiles** — pearls colored by owner (blue yours, red enemy), every other projectile gets a plain hitbox
- **Weapon filter** — hitboxes only show while you hold a weapon or item you picked: swords, axes, mace, trident, spear, bow, golden apple, totem and more
- **Out of range** — hitboxes dim when the entity is out of attack range
- **Everything gets a hitbox** — boats, minecarts, items, every entity, like vanilla F3+B but colored
- **More control** — line width with distance switch, outlines, every color configurable
- **17 Minecraft versions** — from 1.21 to 26.3, a separate jar for each
- **8 languages** — English, Russian, Ukrainian, Polish, German, Spanish, French, Brazilian Portuguese

Everything is configurable in Mod Menu: 4 clean tabs, no clutter.

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Drop the jar for your Minecraft version into `mods` together with
   [Fabric API](https://modrinth.com/mod/fabric-api) and
   [Cloth Config](https://modrinth.com/mod/cloth-config)
3. Open Mod Menu → Combat Hitboxes+ → Config
